AI-Powered Customer Support Email Automation using n8n

Project Overview

This project automates customer support using n8n and Gemini AI. 
It receives customer messages from a React application,
classifies them into categories using AI, generates professional responses, and automatically sends email replies through Gmail.

---

 Features

* AI-powered customer query classification
* Automatic reply generation using Gemini AI
* React frontend integration
* Webhook-based communication
* Gmail email automation
* Category-based routing with Switch Node
* Error handling for failed API responses
* End-to-end workflow automation



Tech Stack

* n8n
* React.js
* JavaScript
* Gemini AI
* Gmail
* REST API
* Webhooks
* JSON

---

 Workflow

1. User submits a message from the React application.
2. Webhook receives the request.
3. Gemini AI classifies the customer query.
4. AI generates a professional response.
5. Switch Node routes the request based on the category.
6. Gmail sends the automated email.
7. Respond to Webhook returns the AI response to the React application.
